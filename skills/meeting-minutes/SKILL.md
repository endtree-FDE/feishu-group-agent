# 整理会议纪要

1. 只根据用户给出的文字、当前话题里已经出现的对话，以及已经读到的群消息来整理。没有的信息写「未提及」，不要编。
2. 按四段输出：结论、待办、负责人、截止。某一段没有内容就写「无」。
3. 待办每条一行。能对应到负责人或截止就写上，对不上就标「待定」。
4. 不写入。不要新建文档，不要往文档、表格或日历里写。用户如果希望落成飞书文档，说明需要另行确认，本技能只负责整理文字。
