# 查进度表

1. 用已启用的 base_read 读取团队多维表格。要缩小范围时，在参数里带上 keyword。
2. 只根据表格返回的记录回答。表里没有的项写「表里没有」，不要猜，也不要补虚构的任务。
3. 先说一句结论，再列出未完成、并且临近截止的项，最多 5 行。每行包含任务、负责人、截止、状态；缺的格子写「未填」。
4. 不要改表，不要新增记录。用户要求修改时，说明需要写入白名单里的人另行发起，并走确认码。
