# 记忆与命令

机器人有两种记忆。一种是「这几句话接着聊」，一种是「这个群要一直记住的事」。下面说的命令，管的是第二种。

长期记忆默认是关的。配置里 `memory.enabled` 为 `true` 才生效。谁能改，见下面「谁可以用」。

## 谁可以用

| 你想做的事 | 谁可以 |
|---|---|
| 在群里看记忆（`/记忆`） | 能 @ 到机器人的群成员 |
| 往群记忆里加一条、删一条、清空 | 只有配置 `write.allowed_users` 里的人（写入白名单） |
| 给新群建一份自己的档案目录 | 自动认群认下这个群时，马上建 `memory/groups/群编号/`。只写在 `chat_ids` 里的群，仍是第一次「记一下」时才建。没认的群不建，也不记 |
| 在私聊里使用这些命令 | 可以发，但**不会写进任何群**。私聊会告诉你：要记群里的事，请到群里 @ 机器人 |

不在白名单的人说「记一下」，机器人会拒绝，并且不落盘。

模型也可以提议记一条（工具 `memory_propose`）。它不会直接写入，而是发一个 6 位确认码，必须**发起人本人**在原会话里回复「确认 123456」才落盘。别人拿着码不行。没确认的内容不能当成已经记住。确认写入之后，这个群已经开着的话题会换上新的档案，不用等会话过期。

个人记忆（按每个人记一份）默认关闭。私聊里说的偏好，不会被拿到群里去讲。

## 记一下

在群里 @ 机器人，发送：

```text
记一下：讨论会：改到周四下午 3 点
```

也可以用「记住：……」或「备忘：……」。这两个后面要有冒号、逗号或空格。「记住了吗」**不是**命令，会当成普通问题。

成功时它回复「已记 #编号」，并告诉你这条被分成哪一类（例如截止、决定、成员）。

写法建议带主题：

```text
主题：内容
```

冒号前面是主题（不超过 20 个字）。同一个主题再记一条，新的生效，旧的标成「已被取代」，不删历史。下次再问，用的是新的。

限制：

- 太短（少于 2 个字）或太长（默认超过 300 字）会被拒绝。
- 客户名会换成「某客户」。手机号、证件号、邮箱、密钥样子的字符串、电脑路径会被打码。回复里会说「已自动隐藏」。
- 如果这个机器人配置了话题红线，并且规则管到记忆，命中的内容不记。
- 图片和文件本身不进记忆。

## /记忆

在群里 @ 机器人，发送：

```text
/记忆
```

`记忆`、`/记忆 群`、`/memory` 是一样的。

它列出本群还在用的条目，每条前面有编号。被取代的旧条目不展开，只说还有几条。这一步不调用模型。

私聊里发 `/记忆`，它会说明私聊没有群档案，请到群里看。

## /忘记

在群里 @ 机器人，发送：

```text
/忘记 9
```

`/忘记 #9`、`忘记 9` 也可以。编号就是 `/记忆` 里看到的那个。

这是**真删**：那一条从账本里拿掉，以后回答不再使用。审计里只留下编号和时间，不留下原文。

编号不存在，它会说没有找到。不在白名单的人不能删。删掉的编号不会再用给新的条目。

## /忘记全部

在群里 @ 机器人，发送：

```text
/忘记全部
```

它不会立刻清空。它给你一个 6 位数，并请你在 5 分钟内回复：

```text
确认清空 123456
```

（把数字换成它给你的那一个。）

必须是**同一个人、在同一个群**里回复。别人拿着这个码不能清。码错了、过期了、用第二次，都不会清。清空不能恢复。

## 和「新话题」的区别

```text
新话题
```

或 `/new`、`/reset`。这只清掉**当前话题最近几轮**的上下文，方便换个事聊。它**不**删除「记一下」记进群里的长期记忆。

这几轮加起来超过 `memory.context_budget_chars`（默认 8000 字）时，更早的整条不会交给模型，数据库里的记录还在。默认会在提示词里加一句省略了几条。`memory.trim_note` 写成 `false` 就不再加这句。短对话不超过预算，提示词和以前一样。

## 记在哪里

每个机器人一个目录，每个群再分开：

```text
memory/groups/<群编号>/GROUP.md
memory/groups/<群编号>/facts.jsonl
memory/_audit/memory-audit.jsonl
```

`GROUP.md` 是给模型和人看的短档案。`facts.jsonl` 是一条一行的账本。别的群的文件夹，这个群的回答不会去读。

档案超过 `profile_budget_chars` 时，后面的条目不会整段放进每一题。长期记忆开着、并且没有把 `memory.recall` 写成 `false` 时，如果这一题的用词命中了被截掉的条目，程序只把那几条（已脱敏、还有字数上限）补在这一题前面。这不写入档案，也不等于已经确认。要改档案，仍要白名单成员发「记一下」，或由发起人确认模型提出的那一条。
