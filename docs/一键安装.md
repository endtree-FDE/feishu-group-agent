# 一键安装

这份说明给第一次在 Windows 上装飞书群机器人、平时不改配置文件的人。按向导的提问做就行。一次只问一个问题。每一问都会告诉你为什么要填、去飞书的哪一页看、直接回车会用什么。

向导不会替你登录，也不会把 App Secret 或模型密钥写进文件。

## 你要先准备什么

- 一台 Windows 电脑
- 一个能创建「企业自建应用」的飞书账号
- 你自己的 Cursor 账号（如果选择默认模型）

仓库里没有任何人的账号、群号或密钥。下面的例子都是编的：机器人叫「小助手」，主人叫小李。

## 怎么开始

1. 下载这个仓库，用资源管理器进入那个文件夹。
2. 在文件夹地址栏输入 `powershell`，回车，打开蓝色窗口。
3. 粘贴下面这一行，回车：

```text
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup.ps1
```

窗口会用中文一题一题问你。看不懂某一句，就把那一句发给懂的人，不要把 App Secret 一起发过去。

不想真的写入文件、只想先看它会问什么：

```text
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup.ps1 -DryRun
```

Mac 或 Linux 上用同一套提问，在仓库根目录执行：

```text
python setup_wizard.py
```

只演练、不写文件：

```text
python setup_wizard.py --dry-run
```

## 它会问什么

1. **这台电脑缺不缺程序。** 看 Python、Git、飞书命令行 `lark-cli`、Cursor 命令在不在，以及 Cursor 是不是已经登录。缺了会告诉你去哪装。向导不会自动安装，也不会执行登录。
2. **配置名字。** 直接回车用 `assistant`。这是你电脑上的文件名，不用去飞书找。
3. **群里显示的名字。** 直接回车用「小助手」。
4. **App ID。** 浏览器打开 `https://open.feishu.cn/app` ，进入你的企业自建应用，点「凭证与基础信息」，复制 App ID。它以 `cli_` 开头。
5. **这台电脑上的登录名字。** 直接回车就用配置名字。一台电脑有几个机器人时，每个都要不同，避免盖掉别人的登录。
6. **App Secret。** 还是「凭证与基础信息」那一页。粘贴时屏幕上不显示。向导只把它交给下面这条命令，从标准输入送进去，不出现在命令文字里：

```text
lark-cli config init --name 你的登录名字 --app-id 你的AppID --app-secret-stdin --brand feishu
```

7. **选群。** 向导会列出机器人已经加入的群。输入序号，直接回车选第 1 个。一个都查不到时，可以手填群编号（以 `oc_` 开头）。请先在飞书群里把这个应用加为群机器人。
8. **谁是主人，哪个是机器人自己。** 查得到就选序号，查不到就手填以 `ou_` 开头的编号。主人以后可以在私聊里发「设置」。不要选机器人自己当主人。
9. **人设。** 直接回车是「通用」。也可以选黑客松小组、工作室、课题组。安全规则都一样。
10. **模型。** 直接回车用 Cursor。也可以选 OpenAI 兼容接口或 Claude。选后两家时，配置里只写环境变量的名字，例如 `OPENAI_API_KEY`。不要把密钥粘贴给向导。
11. **检查。** 向导会自己跑配置检查和诊断。每一条失败和提醒都用白话说明怎么处理。
12. **计划任务和看门狗（可选）。** 直接回车表示先不创建。输入 `y` 才在你登录 Windows 之后自动启动，并每 5 分钟看一眼还活着没有。不保存 Windows 密码。
13. **现在启动吗（可选）。** 直接回车表示先不启动。输入 `y` 才启动。同一个飞书应用已经有一个接收进程时，向导会拒绝再开一个，也不会去结束那一个。

## 装好以后

用主人的飞书打开和机器人的**私聊**。启动成功后，它会发一段自我介绍，并告诉你可以发送「设置」。

这段话只在私聊里，不会发到群里。

用量周报、知识检索、记忆成长、早间待办、断线提醒、技能默认都是关的。要开的话，在私聊里发「设置」。卡片上的功能名例如「用量周报」「离线告警」，可以一次勾几项，确认一次即可。卡片回调没连上时，回复序号，例如 `1 5`。说明见 [新手开关功能.md](新手开关功能.md)。

私聊谁能用，沿用配置里的 `p2p.allow_group_members`（向导保持示例里的关）。主人因为在写入名单里，可以私聊。向导不会改成「所有人都能私聊」，也不会把整个群都加进写入名单。写入仍然要主人本人确认。默认在卡片上点「确认」或「取消」；飞书没开通卡片回调时，自动改回 6 位确认码。见 [确认方式.md](确认方式.md)。文档、日历、表格的位置先空着，空着就不会往飞书里新建东西。

## 中途关掉了

再运行一次同一条命令。它会问要不要接着上次。直接回车表示接着。

进度记在这台电脑的 `state/setup-draft.json`。里面有你填过的名字和编号，**没有** App Secret，也没有模型密钥。密钥如果上次没保存成功，会再问一次。

已经有同名配置时，向导先复制一份备份到 `state/config-backups/`，再更新那份配置。备份和原文件都留着，向导不删除它们。

## 不想在窗口里一题题打

可以准备一份答案文件，给检查脚本用。答案里可以暂时写上 App Secret，向导只会把它交给飞书命令行，不会抄进配置或草稿。更稳妥的做法是干跑时不写密钥。

```text
python setup_wizard.py --dry-run --answers answers.json
```

`answers.json` 不要提交到公开仓库。干跑不会写配置，不会调用保存密钥的命令，不会创建计划任务，也不会启动。

答案文件是普通 JSON。名字用英文。人设用 `general`、`hackathon`、`studio` 或 `lab`。模型用 `cursor`、`openai_compatible` 或 `anthropic`。`create_tasks` 和 `start` 写成 `false` 就先不做。

## 常见问题

**窗口一闪就没了。** 请在仓库文件夹里打开 PowerShell，再运行上面的命令。不要只双击一个会马上关掉的窗口。

**提示找不到 Python。** 安装 Python 3.12，勾选加入 PATH，关掉窗口重开。这不在飞书后台里。

**提示找不到飞书命令行。** 先安装 Node.js，再在新窗口执行 `npm install -g @larksuite/cli`。向导不会替你安装。

**Cursor 还没登录。** 请你自己执行 `cursor-agent login`，用你自己的账号。向导不会执行登录，也不会改你已经登录的账号。

**App ID 总说不对。** 到「凭证与基础信息」复制 App ID，不要把 App Secret 填进这一格。App ID 以 `cli_` 开头。

**粘贴 Secret 时屏幕没变化。** 这是正常的。粘贴后直接回车。不要把它再贴到聊天或配置文件里。

**列不出群。** 先在飞书群里添加这个应用作为群机器人，并在开放平台「版本管理与发布」里发布版本。也可以手填群编号。

**列不出人。** 手填编号。编号以 `ou_` 开头。同一个人换一个应用后编号会变。不要填手机号。

**检查里有失败。** 看向导那一行白话。常见情况是：飞书命令行还没装、应用还没发布、网络上不了飞书、或者模型的环境变量还没在这个窗口里设置。处理完再跑一次向导。已经写好的配置会先备份再改。

**检查里有提醒。** 提醒一般还能继续用。例如还没装看 PDF 的包，不装也能聊天，只是 PDF 会说明读不了。

**它说已经有一个在跑。** 同一个应用只能有一个接收进程。不要再开一个。要停下原来的，在仓库目录运行：

```text
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop.ps1
```

向导自己不会结束那个进程。

**自我介绍没收到。** 用主人的飞书打开和机器人的私聊，而不是去群里等。确认启动时窗口里出现了已启动。群里不会有这段介绍。

**想改人设或模型。** 再跑一次向导。旧配置会先备份。

**想开某项功能。** 不要改文件。主人私聊机器人，发送「设置」。见 [新手开关功能.md](新手开关功能.md)。

**想先不连飞书，只跑仓库自带的检查。** 看 [快速开始.md](快速开始.md)。那四条命令不需要应用，也不写密钥。

## 和手写配置的关系

向导生成的是 `agents/你的名字.json`。这个文件已经被忽略，不要提交。每一项的含义仍以 [agents/CONFIG.md](../agents/CONFIG.md) 为准。想自己逐项核对时，看 [新建智能体.md](新建智能体.md)。
