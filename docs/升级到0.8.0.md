# 从 0.7.0 升到 0.8.0

这一版不改配置也能接着跑。程序不读 `VERSION`。不要把 App Secret、群号、open_id 或客户名写进配置或聊天。

发布说明见 [v0.8.0](release-0.8.0.md)。0.7.0 的停机步骤见 [升级到 0.7.0](升级到0.7.0.md)。

这一版在 0.7.0 之后多了两件事，旧配置不用改：

- 第一次安装可以用向导，一题一题问。已经有配置的人不用跑。入口见 [一键安装](一键安装.md)。
- 写入默认在卡片上点「确认」或「取消」。没写 `confirm` 时就是这样。飞书还没开通卡片回调时，自动退回 6 位确认码。确认不能关掉。见 [确认方式](确认方式.md)。

下面的步骤把代码换成这一版。这份说明不打标签。标签 `v0.8.0` 由发布时另打。标签还没打时，不要执行 `git reset` 到一个还不存在的标签。

## 换代码

在这个机器人的仓库根目录操作。看门狗大约每 3 分钟看一次心跳。进程停了而代码还是旧的，它会把旧程序再拉起来。所以 `scripts\stop.ps1` 和换代码必须在同一步里连续执行。

1. 进程可以先留着。先把 `main` 取到本机。标签打出来之后，把下面的 `origin/main` 换成 `v0.8.0`：

```text
git fetch origin main
```

2. 同一步。在 Windows PowerShell 里整段一次贴上。先停，停成了立刻换代码。中间不要启动。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop.ps1
if (-not $?) { throw "stop.ps1 没停成，先不要换代码" }
git reset --keep origin/main
if (-not $?) { throw "代码还没换成这一版，先不要启动" }
```

`stop.ps1` 仍只看本目录和 profile，不会结束旁边另一个机器人。`git reset --keep` 把已跟踪的程序文件换成这一版，并留下不冲突的本地修改。它不删除未跟踪和被忽略的文件：你自己的 `agents\*.json`、`state`、`kb`、`memory`、`redact.txt`、`logs` 都还在。不要用 `git reset --hard`，也不要 `git clean`。

3. 用原来的启动脚本再启动。把配置名换成你这份：

```text
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start.ps1 -Config agents\<名字>.json
```

旧配置不必补 `confirm`。没写时按点按钮；卡片回调还没开通时自动退回确认码。

## 换上之后检查

在仓库根目录。两条都不发消息。`--doctor` 不写心跳，不拿单实例锁，也不启动收消息的进程。

```text
python checks/check_config.py agents\<名字>.json
python agentbot.py agents\<名字>.json --doctor
```

要用卡片按钮，到飞书开放平台这个应用里：事件与回调 → 使用长连接接收事件 → 添加 `card.action.trigger` → 发布版本。不需要公网地址。没添加时，`--doctor` 会警告并写出这几步，机器人仍用确认码，不要把它当成启动失败。

## 退回 0.7.0

退回目标是提交 `26f37c5`。当时 `VERSION` 文件仍是 `0.7.0`，已经有安装向导，还没有卡片按钮确认。

同样必须同一步：先 `stop.ps1`，停成了立刻换回。不要拆开。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop.ps1
if (-not $?) { throw "stop.ps1 没停成，先不要换代码" }
git reset --keep 26f37c5
if (-not $?) { throw "代码还没换回去，先不要启动" }
```

然后再用那一版的 `scripts\start.ps1` 启动。`git reset --keep` 仍保留你的配置、`state`、`kb`、`memory` 和 `redact.txt`。

`26f37c5` 不认 `confirm` 这一节，多出来的键会被忽略，写入仍要 6 位确认码。安装向导还在。`state` 里若留下卡片确认记录，留着也没有关系，那一版不读这些记号。
