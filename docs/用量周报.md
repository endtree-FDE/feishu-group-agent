# 用量周报

默认关。旧的 `agents/*.json` 不写 `report` 时，行为和以前一样：不到点私聊，`/状态` 也不多这一行，`/report` 仍交给模型。

这是私聊给主人的合计，不是群消息。框架里会主动发到群里的，仍然只有早晨摘要。密钥、open_id 和群编号放在你自己的配置里，不要提交，也不要写进周报。

## 什么时候发

`report.enabled` 为 `true` 才到点发送。时间不写是周一 `09:00`，时区不写是 `Asia/Shanghai`。到点之后的 `window_min` 分钟内还可以补发，不写是 180。写成 `0` 只在那一分钟。写成负数时按 180。

统计周从配置的星期 0 点起，共 7 天，报的是**刚结束的那一周**。周一 09:00 发出的是上周一 0 点到本周一 0 点。每个主人每周一份。先在 `state/report_state.json` 里占坑再发，重启落在同一窗口里不会再发。发送明确失败会放掉名额，下次补发；超时或看不懂结果就保持占坑，避免发两份。状态文件里只有星期和主人编号的哈希，没有 open_id。

`weekday` 可以写 `mon` 到 `sun`、`周一` 到 `周日`，或 `0` 到 `6`（`0` 是周一）。认不出来就不发。`time` 不是 `HH:MM`、时区认不出来，也不发。

接收人：`report.owner_open_ids` 里有可用编号时用它，否则用 `alerts.owner_open_ids`。不要求 `alerts.enabled` 已经打开。`REPLACE_` 开头、空的、或明显不是编号的会丢掉。两边都没有可用编号时不发，本机记一行，不把编号写进日志。

演练（`--dry-run`）、测试用的模型或飞书替身、自检和 `--doctor` 都不发送。

## 主人临时看一份

打开之后，主人可以发 `/report`。

- 私聊里直接回复这份周报。
- 群里只回「已私聊发送用量周报。群里不贴明细。」明细走私聊。
- 不是主人，回「只有主人可以查看用量周报。」不附合计。
- 这条不占每周一次的名额。

没打开时，`/report` 不是命令，仍交给模型。

不发送、只在本机看：

```bash
python agentbot.py agents/<名字>.json --report
python agentbot.py agents/<名字>.json --report --week 2026-W42
python agentbot.py agents/<名字>.json --report --week 2026-10-12 --out 周报.md
python agentbot.py agents/<名字>.json --report --out 周报.csv
```

`enabled` 为 false 时这几条仍可用。`--week` 写成 `2026-W42` 时按 ISO 周（周一起）。写成 `YYYY-MM-DD` 时，取包含这一天、并从配置的星期 0 点起的 7 天。写错、时区认不出来，或 `--out` 不是 `.md` / `.csv`，退出码是 2，不发消息。`.csv` 用带 BOM 的 UTF-8，方便表格软件打开。

## 统计什么

来源是本机 `logs/usage.jsonl`（大约 4MB 后轮转到 `.1`）。按群各一份，再加合计。每一项都有上一周的数字和变化。群在周报里写成「群 1」「私聊 2」。`state/usage_groups.json` 只存聊天编号的哈希和这个标签。

| 指标 | 口径 |
|---|---|
| 处理问题 | 交给模型的题，以及被话题红线拒绝的题。命令、限流、队列满了不记 |
| 完成回答 | 有正文，并且不是「时间到了先给一部分」 |
| 响应时间 | 中位数和 P90，单位在正文里写成秒。红线拒绝不计入，避免把 0 秒拉低中位数 |
| 工具 | 网页搜索、打开网页、文档、日历、多维表格。打开网页只有真的用过才单独一行 |
| 读文件 | 只按扩展名，例如 `pdf`、`docx`。没有扩展名记 `unknown`。不记原文件名 |
| 写入 | 提议、确认、取消、过期。过期只记动作，不把待写入的正文再抄一遍 |
| 脱敏命中 | 只记次数。同一处文字在提问、审计、回复各计一次，不记被换成占位符的原文 |
| 错误 | 模型报错、模型超时、权限不够。权限看飞书错误码和「无权限 / 权限不足 / 没有权限」 |
| 连接中断 | 长连接从连上变成断开的次数，以及这段时间内的累计秒数。只出现在合计里 |
| 健康提醒 | 断线提醒发出的中断、仍未恢复、恢复。只出现在合计里，不是连接中断的重复 |
| 问题类别 | 帮助、记忆、日历、表格、文档、文件、搜索、写入、其他。只留前几类，不留原话 |

连接中断按时间重算。一周开始前已经断开的，不重复计次，只把落在本周里的秒数算进来。第一次连上不算恢复。

演练和补答会记进行，但周报底部只写「未计入演练 N 条、补答 M 条」，不进上面的数字。停机时如果题还没记下来，补答会标成补答，这份周报里就看不到那一题，避免和崩溃前已经记下的那条算两次。

## 不会写进去的东西

- 问题原文、回复原文、工具参数、网页标题和搜索词
- 人名、客户名、手机号、密钥
- open_id、群编号、消息编号、文件名和路径

计数文件只接受固定的种类和 `g1` 这种标签。混进来的原文或编号整行丢掉，不会出现在周报里。
