# 排障

这里的例子都是编的。机器人叫「示例助手」，配置文件叫 `agents/demo.json`，人叫小李。不要把真实的群号、用户编号、密钥或电脑用户目录贴到 Issue 里。

## 先看哪

在仓库根目录运行：

```text
python agentbot.py agents/demo.json --doctor
```

`--doctor` 只读：登录、权限、事件订阅、网络、依赖、是不是已经有一份在跑。不发消息，不写心跳。Windows 上还可以运行：

```text
powershell.exe -File scripts\verify_windows.ps1 -Config agents\demo.json
```

请用 `powershell.exe`（Windows PowerShell 5.1），不要换成 PowerShell 7 的 `pwsh`，除非你知道自己在比哪一种语法。这个脚本不发消息。含中文的 `.ps1` 必须以 UTF-8 BOM 保存，否则 Windows PowerShell 5.1 会把中文注释解析错。

## 日志

两份日志都在运行的那台电脑上，不要提交。

| 文件 | 记什么 | 不记什么 |
|---|---|---|
| `logs/events.jsonl` | 消息编号、工具名、是否成功、飞书错误码、耗时 | 问题原文。手机号、邮箱、密钥样子的字符串会打码 |
| `logs/journal.jsonl` | 群聊或私聊、字数、耗时、工具名 | 问题原文、参数、路径、编号 |

`observability.journal` 写成 `false` 时不再追加 `journal.jsonl`。`events.jsonl` 没有单独的开关。大约 2MB 轮转，保留 5 份。

## 常见现象

**答到一半没声音，过几分钟才说时间到了。** `agent.stall_sec` 是「完全没有新输出」多少秒算卡住，不写是 `300`。写成 `0` 或负数时仍按 300 秒，不能把卡死检测关掉。`progress_heartbeat_sec` 写成 `0` 只是不打进度心跳，不改变卡死判断。

**停机时正在答的题丢了。** `shutdown_wait_sec` 不写是 15 秒，用来等这一题写完。写成 `0` 表示马上退出，没答完的留在 `state.db`，下次启动补答。不要把这项理解成「再去群里发一条」。

**电脑睡醒之后不再收消息。** `link_jump_sec` 不写是 20 秒。休眠超过这个时间就重连长连接。写成 `0` 表示不因为休眠去重连。进程自己退出后，下次启动仍会连接。

**停机期间的 @ 没有补上。** `catchup.max_age_sec` 不写是 `43200`（12 小时）。更早的消息不会补。写成 `0` 表示不再另加这条时限，仍受心跳和条数限制。第一次启动、没有心跳文件时不回扫。

**模型说看过文件，但正文不对。** 历史里的当前会话附件要走 `message_attachment`，不能把 `file_` 编号当成云文档。一次回答默认最多读 4 个附件（`max_per_answer`）。只读工具默认最多连续 4 轮（`max_tool_rounds`），每一轮可以读多个。写操作提议之后就停，等小李回复 6 位确认码，不会在同一轮里真的写入。

**想换 DeepSeek、通义、智谱或盘古。** `model_provider` 写成对应的预设名，或写成 `openai_compat` 再写 `agent.preset`。预设只填空着的地址、模型名和变量名。密钥放在那个环境变量里，不要写进 JSON，也不要写进 `base_url`。没写 `model_provider` 时仍用本机 Cursor。

**配置检查失败，提示密钥。** `python checks/check_config.py agents/demo.json` 发现 `api_key_env` 不像变量名，或 `base_url` 里夹了密钥，就会失败。它不把密钥再打印一遍。改成变量名之后再检查。

**PowerShell 报语法错误，而且报错位置在中文注释上。** 用 UTF-8 带 BOM 重新保存那个 `.ps1`。仓库里的脚本按这个约定。CI 在 `windows-latest` 上用 `powershell.exe` 解析全部 `.ps1`，缺 BOM 的中文脚本过不了。

## English

Run `python agentbot.py agents/demo.json --doctor`. It does not send messages. `logs/events.jsonl` stores tool names and Feishu error codes. `logs/journal.jsonl` stores character counts. Neither file stores the question text. Keep API keys in environment variables. Save Chinese `.ps1` files as UTF-8 with a BOM so Windows PowerShell 5.1 can parse them.
