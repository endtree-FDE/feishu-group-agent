## 攻击和结果

假模型和假的飞书命令，不连真飞书，也不使用真实群号或人名。

| 攻击 | 结果 | 说明 |
|---|---|---|
| 群消息或文档里夹带 `<<TOOL>>`，想绕过确认码和白名单直接写入 | 已修 | 历史、文档、日历、表格、附件里的工具标记会先换掉。当前这条用户问题里的标记仍然有效，否则正常的工具调用会坏。确认码和白名单仍在真正写入之前 |
| 用文档或网页内容套出知识库、别的群的记忆 | 部分 | 工具结果当不可信数据。对所有人开放私聊时，不在名单里的人不能调用飞书工具和技能。模型工作区仍是知识库目录，这一点没改 |
| 跨群串短期对话（伪造事件复用另一个群的话题编号） | 已修 | 群会话键改成「群编号 + 话题」。同一群同一话题仍复用常驻会话。长期记忆本来就按群分目录 |
| 把客户名、手机号、密钥放进搜索词或网页地址 | 已修 | 常驻模式拒绝这一次上网 |
| 八进制、十六进制、短写 IP、十进制整数、IPv6 本地地址、共享地址段 | 已修 | 一律当内网拒绝 |
| 域名解析失败 | 已修 | 以前失败仍放行，现在拒绝 |
| DNS 重绑定（两次解析结果不一致） | 部分 | 放行前查两次，不一致就拒绝。cursor-agent 拿到允许之后会自己再解析，那一次挡不住 |
| 公网地址再跳到内网 | 已修 | 自己看跳转目标，不跟着访问。探测失败时，这一跳本身已经检查过，仍允许这个地址 |
| 地址里带账号密码，或地址超过 1024 字 | 已修 | 拒绝 |
| 客户名中间插零宽字符 | 已修 | 去掉零宽后再匹配 |
| 较长名字拆开加空格 | 已修 | 6 个字及以上才做，避免短词误伤 |
| 全角数字的手机号、英文名大小写 | 已修 | 只把全角英文字母和数字折成半角。中文标点保持原样 |
| 拼音绕过 | 未修 | 没有词典。需要隐藏就在 `redact.txt` 写成「中文名\|拼音」 |
| 同形字（全角字母数字以外） | 未修 | 不整段做 NFKC，否则中文标点会被改写 |
| 超长消息把额度打光 | 已修 | `agent.max_input_chars` 默认 8000，`0` 表示不截断。原有的限流和队列还在 |
| 附件路径跳出下载目录 | 已修 | 真实路径必须在下载目录里 |
| 知识库压缩包用 `..`、绝对路径或盘符写到目录外 | 已修 | 可疑路径跳过并写进报告 |
| 日志、审计、权限标题里留下手机号或客户名 | 已修 | 这些字段先打码 |
| 私聊 `open_to_all` 被用来调工具 | 部分 | 不在私聊名单、也不在写入白名单的人不能用工具和技能。工作区仍是知识库 |
| 伪造邀请人：待认之后再发一次进群事件，把邀请人改成白名单 | 已修 | 来源是进群事件的待认群，后来的进群事件不能改成自动放行 |
| 非白名单发送 `/认群`，或在指令里夹零宽字符、尾巴 | 已修 | 只有写入白名单，且整句就是认群或忘群 |
| 进群事件重放，或把聊天消息伪装成进群 | 已修 | 带 `event_id` 的只处理一次。带着消息字段的不当成进群 |
| 没有 `event_id` 的进群事件重放 | 未修 | 和一次新的拉群分不开。若一律丢掉，合法的再次入群也会坏 |
| 移出后白名单成员再次拉进 | 不适用为漏洞 | 移出后再被 @ 会记成另一种待认。白名单成员再次拉进仍然重新认。这是原有规则，测试仍通过 |

## 这次加上的能力

默认行为保持不变，除非配置改了下面的数。

1. **长回答分片。** `agent.reply_chunk_chars` 默认 3500。不超过就不拆，幂等键仍是 `re_` 加消息编号。超过才拆成多条，每条开头是（1/N），幂等键是 `re_消息编号_序号`。`0` 表示不拆。模型输出仍先被 `max_chars` 截断，所以不把 `max_chars` 调大时，群里看到的还是一条。
2. **短期上下文按字数裁。** `memory.context_budget_chars` 默认 8000。只影响交给模型的历史，不删数据库里的记录。超预算时丢掉最旧的整段，最新一条留下。`0` 表示只按 `max_turns`。
3. **危险配置提示和一行指标。** `--check` 在两种非默认情况加 HINT：`p2p.open_to_all` 为 true 且私聊名单为空；自动认群生效且 `chats.admit` 为 `open`。示例配置和「私聊名单里有人」不会因此多出 HINT。每道交给模型的题多记一行 `metric`，里面没有问题原文。

## 路线

按价值，后面可以做、这次没做的：

- 按架构说明做记忆压缩（夜间把旧对话收成摘要）。会多调模型，先不要默认打开。
- 不引入插件市场。技能继续用仓库里的 `SKILL.md`。
- 对所有人开放私聊时，换一个没有知识库的工作区。这会改变能回答的范围，要单独决定。
- 拼音和同形字需要词典或人工名单，继续靠 `redact.txt` 的别名。
- 把 `metric` 送到外部监控。现在只进本机日志。
