# 换模型

默认仍是这台电脑上的 Cursor。不写 `model`、也不改 `model_provider` 时，回答路径和以前一样：`agent.mode` 为 `acp` 时走常驻进程，否则每题一个进程。

要换成自己的账号，写 `model`。密钥只放在环境变量里，配置里只写变量名。

## 配置

| 键 | 填什么 |
|---|---|
| `model.provider` | `cursor`（默认）、`openai_compatible` 或 `anthropic`。旧的 `model_provider` 仍可用 |
| `model.base_url` | 接口地址，以 `http://` 或 `https://` 开头。不要在问号后面写密钥 |
| `model.model` | 这家控制台里的模型名 |
| `model.api_key_env` | 环境变量的名字，例如 `OPENAI_API_KEY`。不要把密钥写在这里 |
| `model.temperature` | 可选。不写就不传，用这家的默认值 |
| `model.timeout_sec` | 可选。连接超时秒数。不写仍按 `agent.stall_sec` |
| `model.max_tokens` | 可选。回答最长多少 token。Claude 不写时按 4096 |

`model.provider` 写了就以它为准，盖过 `model_provider`。已经写在 `model` 里的地址和模型名，盖过 `agent` 里的同名字段和预设。

`stall_sec`、`max_runtime_sec`、`network_retries`、工具轮数仍看 `agent`。卡住时，已经写出的文字会先发出去。401 不重试。

改完要停掉正在跑的进程再启动。

## 示例

下面四份都是例子。把变量设进环境，不要把密钥写进文件。

OpenAI：

```json
"model": {
  "provider": "openai_compatible",
  "base_url": "https://api.openai.com/v1",
  "model": "gpt-4o-mini",
  "api_key_env": "OPENAI_API_KEY",
  "temperature": 0.2,
  "timeout_sec": 120,
  "max_tokens": 2048
}
```

DeepSeek（同一套 OpenAI 兼容接口，地址和模型名换成 DeepSeek 的）：

```json
"model": {
  "provider": "openai_compatible",
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-flash",
  "api_key_env": "DEEPSEEK_API_KEY",
  "temperature": 0.3,
  "max_tokens": 2048
}
```

也可以把 `model.provider` 写成预设名 `deepseek`，空着的地址、模型名和变量名会补上。通义、Kimi、OpenRouter 同样用 `openai_compatible`，只改 `base_url` 和 `model`。各家地址见 [模型接口.md](模型接口.md)。

Claude：

```json
"model": {
  "provider": "anthropic",
  "base_url": "https://api.anthropic.com",
  "model": "claude-sonnet-4-5",
  "api_key_env": "ANTHROPIC_API_KEY",
  "max_tokens": 2048
}
```

`base_url` 和 `api_key_env` 不写时，Claude 用上面的地址和 `ANTHROPIC_API_KEY`。模型名仍要写，以你账号里能用的为准。

本机 Ollama：

```json
"model": {
  "provider": "openai_compatible",
  "base_url": "http://127.0.0.1:11434/v1",
  "model": "qwen2.5",
  "timeout_sec": 120,
  "max_tokens": 2048
}
```

地址是本机，又没写 `api_key_env` 时，不要求密钥。若写了变量名，这个变量必须存在，放一个占位词即可，例如 `ollama`。

## 工具、进度和上下文

新接口没有 Cursor 自带的读文件和联网。群历史、知识库、飞书文档、记忆提议和写入，仍走原来的 `<<TOOL>>`。写入还是要白名单和 6 位确认码。

同一话题里的上一轮会写进提示词，所以能接着问。发「新话题」仍清空这几轮。

进度卡片还在。模型若流式送出思考（OpenAI 兼容的 `reasoning_content`，Claude 的 thinking），放进默认收起的「思考过程」。这一轮没有思考，就不放这块，也不写「暂无」。Cursor 仍按原来的样子，没有思考时面板里是「暂无」。

接口若在流里带了 token 数，用量周报会多一行「模型用量」。没带就不写。演练和测试不进真实合计。见 [用量周报.md](用量周报.md)。

## 联网搜索

默认关。不写 `search` 时，提示词里不会多出搜索工具，Cursor 那一路也不变。

新接口自己不能上网。需要时打开搜索后端，模型用 `web_search`：

```json
"search": {
  "enabled": true,
  "backend": "tavily",
  "api_key_env": "TAVILY_API_KEY"
}
```

`backend` 还可以是 `searxng`，那时要写你自己的 `base_url`（`http://` 或 `https://`），不要在地址里放密钥。没打开时，模型会被要求直接说明搜不了，不要假装查过网页。

## 怎么放密钥

配置里只写变量名。程序报错时也只提这个名字和 HTTP 状态码。

PowerShell，当前窗口马上生效：

```text
$env:OPENAI_API_KEY = "你的密钥"
```

想让以后新开的窗口也有（当前窗口不会因此更新，要新开一个）：

```text
setx OPENAI_API_KEY "你的密钥"
```

cmd 只对当前窗口有效：

```text
set OPENAI_API_KEY=你的密钥
```

设好之后，用同一个窗口启动或做检查。

## 怎么确认

```text
python checks/check_config.py agents/你的机器人.json
python agentbot.py agents/你的机器人.json --check
python agentbot.py agents/你的机器人.json --doctor
```

变量没设时，这三处都是失败，并写着变量名和上面的设置方法。设好之后，`--check` 会发一次很短的请求。密钥错了一般是 HTTP 401。输出里没有密钥的值。

日志 `logs/bot.log` 里应有 `model provider openai_compatible` 或 `model provider anthropic`。切回 Cursor 时删掉 `model.provider`，或改回 `cursor`，日志里应是 `model provider cursor`。
