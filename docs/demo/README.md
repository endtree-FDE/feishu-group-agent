# 演示图

这里留给以后的示意图或短动图。现在没有图，是为了避免把真实聊天记录放进公开仓库。

替换时请遮住这些内容：

- 群名、人名和头像
- 群号、open_id、文档编号
- 客户名、手机号、邮箱和任何密钥

不要提交一张未打码的真实会话截图。

`switch-list.svg` 和 `switch-confirm.svg` 是「在飞书里开关功能」的占位图，不是真实会话。换上截图时仍要遮住上面列出的内容。

## English

This folder is reserved for a later diagram or short animation. It is empty so a real chat is not published.

Before adding an image, hide group names, people, avatars, chat ids, open_ids, document ids, customer names, phone numbers, email addresses, and secrets. Do not commit an unredacted screenshot.
