# 从 0.6.0 升到 0.7.0

这一版不改配置也能接着跑。程序不读 `VERSION`。不要把 App Secret、群号、open_id 或客户名写进配置或聊天。

发布说明见 [v0.7.0](release-0.7.0.md)。0.6.0 的停机和可选开关见 [升级到 0.6.0](升级到0.6.0.md)。

这一版在 0.6.0 之后多了两件事，新键默认关着，旧配置不用改：

- 不写 `model` 时仍用 Cursor 回答。不写 `search` 时不联网搜索。
- 主人可以在私聊里发「设置」开关已有功能。不增加必须填写的新键。用量周报、知识检索、记忆成长、早间待办、断线提醒、技能没写或原来是关，就还是关。

下面的步骤把代码换成标签 `v0.7.0`。这份说明不打标签。标签由发布时另打。

## 换代码

在这个机器人的仓库根目录操作。看门狗大约每 3 分钟看一次心跳。进程停了而代码还是旧的，它会把 v0.6.0 再拉起来。进程还在时先换文件，跑着的仍是旧程序，锁和新文件也会对不上。所以 `scripts\stop.ps1` 和 `git reset --keep v0.7.0` 必须在同一步里连续执行，不能拆成「先停、过一会儿再换」或「先换、回头再停」。

1. 进程可以先留着。先把标签取到本机：

```text
git fetch origin tag v0.7.0
```

2. 同一步。在 Windows PowerShell 里整段一次贴上。先停，停成了立刻 `git reset --keep`。中间不要启动，也不要去做别的事。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop.ps1
if (-not $?) { throw "stop.ps1 没停成，先不要换代码" }
git reset --keep v0.7.0
if (-not $?) { throw "代码还没换成 v0.7.0，先不要启动" }
```

`stop.ps1` 仍只看本目录和 profile，不会结束旁边另一个机器人。`git reset --keep` 把已跟踪的程序文件换成这个标签，并留下不冲突的本地修改。它不删除未跟踪和被忽略的文件：你自己的 `agents\*.json`、`state`、`kb`、`memory`、`redact.txt`、`logs` 都还在。不要用 `git reset --hard`，也不要 `git clean`。

`git reset --keep` 如果因为已跟踪文件的本地改动冲突而停下，先不要启动。看门狗可能在这几分钟里把旧进程拉起来。处理完提示后，把第 2 步整段再执行一次，然后再启动。

3. 用原来的启动脚本再启动。把配置名换成你这份：

```text
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start.ps1 -Config agents\<名字>.json
```

旧配置不必补 `model` 或 `search`。没写时仍走 Cursor，也不搜索。已有开关不用改。

## 换上之后检查

在仓库根目录。两条都不发消息。`--doctor` 不写心跳，不拿单实例锁，也不启动收消息的进程。

```text
python checks/check_config.py agents\<名字>.json
python agentbot.py agents\<名字>.json --doctor
```

`check_config` 只看类型，缺了的键和不认识的键不失败。示例里的 `REPLACE_` 只是占位。`--doctor` 里有 `FAIL` 就先看那一项，不要在群里发测试消息。这台电脑还没装 lark-cli 时，诊断里会有失败项，这和没发消息是两件事。

没写 `model.api_key_env` 时，不会因为换模型而要求一个新的环境变量。写了变量名却没在当前窗口设置，检查会失败，并只说出变量名，不会把值打出来。

## 可选

想换成自己的接口时，再看 [docs/换模型.md](换模型.md)。只写 `model`，不要把密钥写进 json。`search` 先不要开。

想用私聊开关时，不用改配置。主人私聊机器人，发「设置」。一次只改一项，确认码通过后才会写入。对话里不能改模型配置。群里的人改不了，也不会看到配置细节。步骤见 [docs/新手开关功能.md](新手开关功能.md)。

## 退回 0.6.0

退回目标是标签 `v0.6.0`，提交 `4da9e42`。

同样必须同一步：先 `stop.ps1`，停成了立刻换回标签。不要拆开。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop.ps1
if (-not $?) { throw "stop.ps1 没停成，先不要换代码" }
git reset --keep v0.6.0
if (-not $?) { throw "代码还没换成 v0.6.0，先不要启动" }
```

然后再用这份旧程序的 `scripts\start.ps1` 启动。`git reset --keep` 仍保留你的配置、`state`、`kb`、`memory` 和 `redact.txt`。

0.6.0 不认识顶层的 `model` 和 `search`，多出来的键会被忽略，仍按当时的 `model_provider` 用 Cursor。它没有私聊开关。`state` 里若留下开关备份或引导记录，留着也没有关系，0.6.0 不读这些文件。
