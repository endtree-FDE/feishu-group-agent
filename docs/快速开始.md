# 快速开始

这份说明给第一次打开仓库的人。目标是 15 分钟内在自己的电脑上把检查跑起来，不必先申请飞书应用，也不必把密钥写进文件。下面的名字都是编的：机器人叫「示例助手」，人叫小李。

## 你需要什么

- Python 3.12
- 能打开终端
- 不需要飞书账号，不需要安装第三方 Python 包

真正收群消息还要 Windows、Node.js 和你自己的飞书企业自建应用。那一步在跑通下面四条命令之后再看 [新建智能体.md](新建智能体.md)。

## 四条命令

在仓库根目录执行。

```text
python tests/run_tests.py
python checks/check_config.py agents/example.json
python setup_agent.py --name demo --provider deepseek --dry-run
python agentbot.py agents/example.json --doctor
```

1. 第一条跑离线测试。最后一行打印通过了多少项。全部通过就可以。不要把那个数字抄进别的文档，它会变。
2. 第二条按 JSON Schema 检查示例配置。示例里的 `REPLACE_` 只是占位，检查会提示，但不会因此失败。
3. 第三条干跑安装向导。它把将要写入的配置打印出来，并给出一行计划任务命令。不加 `--write` 时不创建文件，也不注册任务。密钥不要写在命令里。
4. 第四条是只读诊断。它不发消息，不写心跳，不启动收消息的进程。这台电脑还没装 lark-cli 时，输出里会有失败项，这是预期的，不是把群消息发出去了。

## 接下来才连飞书

1. 复制 `agents/example.json`，另存成 `agents/demo.json` 这样的名字。这个文件已被忽略，不会被提交。
2. 把里面的 `REPLACE_` 换成你自己的编号。App Secret 不要写进 JSON。模型密钥只放进环境变量，配置里只写变量名，例如 `DEEPSEEK_API_KEY`。
3. 复制 `redact.example.txt` 为 `redact.txt`。没有要隐藏的客户名就先留空。
4. 在 Windows 上，于仓库根目录运行 `scripts\start.ps1 -Config agents\demo.json`。
5. 部署之后用 `powershell.exe -File scripts\verify_windows.ps1` 再看一遍。这个脚本只在 Windows 上读本机进程，不发消息。

已经有一个机器人、想换成这套：看 [升级已有智能体.md](升级已有智能体.md)。文档里的例子叫「小景」。

命令报错时看 [排障.md](排障.md)。每一项配置的意思看 [../agents/CONFIG.md](../agents/CONFIG.md)。

## English

From the repository root, with Python 3.12:

```text
python tests/run_tests.py
python checks/check_config.py agents/example.json
python setup_agent.py --name demo --provider deepseek --dry-run
python agentbot.py agents/example.json --doctor
```

The first command is the offline suite. The second checks the example config. The third prints a config and a scheduled-task line without writing a file. The fourth is a read-only diagnosis: it does not send Feishu messages. Connecting a real app is the next step, in `docs/新建智能体.md`. Do not put an App Secret or an API key in JSON.
